# Pooled AUC and within-learner discrimination in knowledge tracing

Reproducibility code and derived analysis tables for the manuscript:

**Pooled AUC Does Not Identify Within-Learner Predictive Discrimination in Knowledge Tracing**  
Huynh Anh Khiem, Ton Duc Thang University  
ORCID: 0009-0007-7210-174X

## What is in this repository

- `code/`: analysis, knowledge-tracing baselines, AUC decomposition, and correctness tests.
- `results/`: derived metric and manuscript-table CSV files for the 14 scoring rules reported in the paper.
- `fetch_data.sh`: retrieves the preprocessed benchmark data from the public Gervet et al. (2020) repository.
- `data/README.md`: dataset provenance and redistribution note.

The repository intentionally does **not** redistribute the benchmark interaction files. The original dataset providers and the Gervet et al. preprocessing release retain their own terms of use. Run `./fetch_data.sh` to obtain the benchmark files from their public source. The script stores them under `data/benchmarks/`, which is the path used by the analysis pipeline.

## Scoring rules

The paper evaluates 14 scoring rules: GlobalMean, ItemMean, SkillMean, FrozenAbility, FrozenIRT, RunningAbility, PFA-shared, BKT, Best-LR, Best-LR+I, DKT, DKT+I, SAKT, and SAKT+I.

`PFA-shared` is a constrained PFA-style logistic baseline with a skill-specific intercept and shared transformed prior-success/prior-failure slopes. It is labelled explicitly to distinguish it from canonical PFA with skill-specific success/failure slopes.

## Reproduction

Python 3.11+ is recommended.

```bash
pip install -r requirements.txt
./fetch_data.sh
python3 code/tests/test_gradients.py
python3 code/tests/test_sakt_gradients.py
python3 code/tests/test_leakage.py
python3 code/run_stage1_fit.py
python3 code/run_stage2_metrics.py
python3 code/run_stage3_analysis.py
```

The derived CSV files in `results/` are provided for transparency and comparison with the manuscript. Prediction arrays are not stored in the repository because they can be regenerated by Stage 1. The public package is intended to reproduce the reported analysis from the pinned benchmark release; third-party benchmark licenses remain unchanged.
